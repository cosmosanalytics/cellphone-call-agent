# Northstar Wireless AI call agent

A cell phone carrier call center agent that implements every touchpoint of
"AI Touchpoints of an AI Call Agent": *build the rules first, learn from calls second, then use both on every live call.*

| # | Touchpoint | Code |
|---|---|---|
| 1 | World model / first principles: plans, devices, accounts, bills, roaming zones, state machines, rules engine, expert scenarios | `carrier/world.py`, `carrier/scenarios.py` |
| 2 | Batch voice to script: Whisper, speaker roles, carrier term correction, PII redaction, dialogue acts, facts | `carrier/batch.py` |
| 3 | Batch empirical learning: call-flow model, rules the calls contradict, accept/reject, held-out test, simulator | `carrier/empirical.py` |
| 4 | Live voice to script: microphone -> Whisper base.en with carrier vocabulary + prosody | `carrier/speech.py`, `carrier/nlu.py` |
| 5 | Live script to decision: verify phone + PIN before any account detail, rules tools, human hand-off | `carrier/agent.py` |
| 6 | Live decision to voice: Piper, calmer pacing for frustrated callers | `carrier/speech.py` |
| 7 | Live decision to evaluation: rule checks + LLM judge, held-out replay, human review, agreement | `carrier/evaluation.py` |

All data is synthetic. The 120 past calls (`data/corpus`, `data/audio`) were generated by scripted callers talking
to an agent that runs on the carrier's *hidden* real policies (Unlimited Plus includes Europe roaming; Unlimited
Starter slows after 50 GB, not 100 GB). Stage 3 recovers both from the transcripts alone.

## Run locally

    pip install -r requirements.txt
    streamlit run streamlit_app.py

The password is set by `APP_PASSWORD_SHA256` in Streamlit secrets (sha256 hex of the password); the built-in default is the shared demo password.

Optional open-weight LLM (NLU fallback + live judge): run llama.cpp `llama-server` with Qwen2.5 and set
`LLM_BASE_URL=http://localhost:8081/v1`. Without it the app uses rules NLU and precomputed judge scores.

## Rebuild the offline data (needs a bigger machine)

    python scripts/build_data.py corpus        # scripts + Piper two-voice audio
    python scripts/build_data.py batch 4       # Whisper small.en + WeSpeaker roles
    LLM_BASE_URL=http://localhost:8081/v1 python scripts/precompute_judge.py

## Deploy on Streamlit Community Cloud

1. share.streamlit.io -> Create app -> this repo, branch `main`, main file `streamlit_app.py`, Python 3.12.
2. Deploy. The live page uses Whisper base.en and one Piper voice (downloaded on first use), which fits the ~1 GB limit;
   batch transcripts and the LLM-judge scores are precomputed.
